# Adventure-Works-Insights
 AdventureWorks Power BI Report

## 📊 Overview

This README describes the **AdventureWorks Report_FINAL.pbix** Power BI
dashboard.\
The report provides insights into sales, products, customers, and
performance metrics using the AdventureWorks dataset.

------------------------------------------------------------------------

## 🚀 Features of the Report

-   Interactive dashboards and filters\
-   Sales performance analytics\
-   Product category and subcategory insights\
-   Customer demographics and purchasing patterns\
-   Time‑series trend analysis\
-   KPIs and drill-down visuals

------------------------------------------------------------------------

## 📁 File Included

-   **AdventureWorks Report_FINAL.pbix** --- Main Power BI report

------------------------------------------------------------------------

## 🛠️ Requirements

-   **Power BI Desktop** (latest version recommended)

------------------------------------------------------------------------

## ▶️ How to Use

1.  Download the `.pbix` file.\
2.  Open it in Power BI Desktop.\
3.  Refresh data if needed.\
4.  Explore dashboards, slicers, and visuals.

------------------------------------------------------------------------

## 📌 Notes

-   The report is built on the AdventureWorks DW dataset.
-   Optimized with clean data modeling and DAX measures.
